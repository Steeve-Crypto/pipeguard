# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue in **pipeguard**, please report it privately.

- **Preferred:** Open a [GitHub Security Advisory](https://github.com/Steeve-Crypto/pipeguard/security/advisories/new) on this repository.
- **Alternative:** Contact the maintainer via the GitHub profile linked to this project.

Please include:

1. Description of the issue
2. Steps to reproduce (if applicable)
3. Affected version / commit
4. Potential impact

We aim to acknowledge reports within a few days and will coordinate a fix and disclosure timeline with you.

Do **not** open a public issue for vulnerabilities that could be exploited.
